AstroClaw is a self-hosted AI agent platform that runs entirely in your own AWS account. You deploy it with a single CDK command, connect through a terminal UI or a minimal CLI, and get a persistent, streaming AI assistant that you own end-to-end. This page explains what AstroClaw is, what it can do, and how to choose the right options for your setup.

## What AstroClaw does

AstroClaw runs as a serverless backend on AWS and exposes a REST and WebSocket API. When you send a message, your agent streams a response back in real time over WebSocket. Conversations are stored in a database tied to your AWS account — nothing is sent to a third-party platform.

You configure each agent with a name, a personality ("soul"), and a choice of underlying AI model. Agents can use built-in tools, load skills, and maintain long-term memory across sessions.

## Supported AI providers

AstroClaw works with both **OpenAI** and **Anthropic**. You supply your own API key at deploy time. No proxy, no markup — requests go directly from your AWS infrastructure to the provider.

## Client options

| Client | Best for |
|--------|----------|
| **Terminal UI (TUI)** | Day-to-day use — a full interactive interface in your terminal |
| **CLI** | Scripting and quick one-off queries |

Both clients connect to the same deployed backend using the API URL, WebSocket URL, and API key printed after deployment.

## Database options

| Option | Description |
|--------|-------------|
| **Aurora DSQL** | Serverless, pay-per-request — no idle cost, scales to zero |
| **Aurora PostgreSQL** | Provisioned — predictable performance for heavier workloads |

You choose the database option during the interactive deploy script. Both store data in your own AWS account.
